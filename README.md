#  Backpropagation Visualizer

An interactive visualization that demonstrates how neural networks learn through forward and backward passes.

🔗 **Live Demo:** https://nino-11.github.io/backpropagation-visualizer/

---

##  Overview

Backpropagation is one of the most fundamental algorithms in machine learning, yet it’s often difficult to truly *see* how it works.

This interactive tool provides a step-by-step visual breakdown of:

- Forward pass (activations flowing through the network)
- Loss computation
- Backward pass (gradients flowing back)
- Weight updates via gradient descent

---

##  Features

- Real-time visualization of neural network training  
- Step-by-step forward and backward propagation  
- Adjustable learning rate  
- Multiple datasets (XOR, circle, spiral)  
- Different architectures (shallow vs deep networks)  

---

##  Why I Built This

Backpropagation is typically taught mathematically, but intuition often comes later.

I built this to make the learning process **visual and intuitive**, similar to how I approached:

- K-Means vs DBSCAN
- Gradient Descent Optimizers
